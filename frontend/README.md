# SkillSphere Frontend Design

This is the visual frontend prototype for SkillSphere.

## Included
- Landing page
- Login/Register screens
- Dashboard
- Profile
- Skills
- Find Students
- Projects
- AI Team Match
- AI Skill Gap
- AI Learning Path
- Mentors placeholder
- Study Groups placeholder
- Responsive design

## Run
```powershell
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Important
This is a frontend design/prototype only. It does not yet connect to the Java Spring Boot backend or Neon database. Those will be integrated after the UI is approved.
